# Likitha's Function Hall Booking
## Run
1. Install Node.js.
2. Open terminal in backend.
3. Run: npm install
4. Run: npm start
5. Open the root index.html in a browser.
Backend runs at http://localhost:5000

Features: hall selection, Veg/Non-Veg food, guest count, total calculation, booking confirmation, payment method, and booking list.

Note: bookings are stored in memory for this demo and reset when the server restarts. Payment is demo-only.
